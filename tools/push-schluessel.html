🔔 FireTime Pro – Push-Schlüssel

Dieses Hilfswerkzeug erzeugt deine Push-Schlüssel nur lokal in deinem Browser. Die Daten werden an keinen Server geschickt. Benutze es einmalig für den Cloudflare Worker.

Geheim: Der dritte Wert ist dein privater Schlüssel. Nur als Secret direkt in Cloudflare speichern. Nicht im Chat, E-Mail oder GitHub veröffentlichen.

Schlüssel sicher aufbewahren. Wenn du neue erzeugst, funktionieren alte Geräte-Registrierungen möglicherweise nicht mehr.
